# gitTest

This repository contains simple demo projects.

## Flappy Bird (Python)
`flappy_bird.py` provides a minimal Flappy Bird clone written in Python using pygame. You must install pygame to run it:

```bash
pip install pygame
python flappy_bird.py
```

## Flappy Bird (JavaScript)
`flappy_bird.html` implements a small Flappy Bird-style game in JavaScript using the HTML5 canvas. Open the file in a web browser to play the game.
